# CraftID

CraftID is an EUFUA digital instrument for professional identity, skills and evidence for craftspeople, workshops and craft-based micro-enterprises.

## Product principle

**Identity → Skills → Practice → Evidence → Trust**

CraftID is an independent professional identity and evidence infrastructure. It is not a marketplace, statutory register, professional licence, official qualification, or EU certification scheme.

## MVP

The first release focuses on:
- persistent CraftID identifiers;
- professional and workshop profiles;
- structured craft and skills taxonomy;
- claim-based evidence;
- private evidence storage;
- review workflows and audit trails;
- public trust statuses;
- English and Ukrainian interfaces;
- privacy-safe Discover and Map experiences.

## Architecture baseline

- Next.js
- TypeScript
- Supabase (PostgreSQL, Auth, Storage)
- Vercel
- multilingual architecture from day one (EN + UK at launch)

Project documentation is maintained separately in the CraftID project workspace.
