# CraftID P0 remediation batch 1 — 24 September 2026

This release addresses the first verified P0 items from the architecture/content audit.

## Included

- Align recent repository migration filenames with the production migration ledger.
- Document the environment-specific initial admin bootstrap migration without committing its fingerprint.
- Restore the production partner-logo hardening migration in source control.
- Correct the CraftID certificate assurance language:
  - rename the user-facing artefact to **CraftID Record Certificate**;
  - describe it as a versioned snapshot of a published CraftID record;
  - explicitly state that it does not by itself verify legal identity or professional competence.
- Fix the CraftID entity update guard so it does not compare a generated check-digit column inside a BEFORE UPDATE trigger.
- Add continuous publication-readiness enforcement for profile, privacy and claim changes.
- Revalidate existing published entities and move records that fail the current publication gate back to draft with an audit event.

## Deliberately not included

The full legal privacy notice remains a separate owner/legal approval task because controller details, lawful bases, retention periods, processors/transfers and complaint/contact information must be approved rather than inferred from code.
